# Voila (여행 블로그) PRD

> PRD(제품 요구사항 문서)는 "무엇을, 왜, 어떻게 만들지"를 정리한 설계 문서입니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | Voila (여행 블로그) |
| 목적 | Notion을 CMS로 활용한 개인 여행 기록 블로그 |
| 현재 상태 | 현재 폴더는 Vite + React Starter Kit이며, 구현 단계에서 Next.js 15 기반으로 전환할 예정입니다. |

### CMS란?
CMS(콘텐츠 관리 시스템)는 글과 사진을 쉽게 쓰고 관리하는 도구입니다.
Voila는 Notion을 CMS로 사용합니다.

### Notion을 선택한 이유
- Notion에서 글을 쓰면 별도 개발 없이 블로그에 자동 반영됩니다.
- 평소 쓰던 메모 앱 그대로 여행 기록을 작성할 수 있습니다.
- 글을 올리려고 코드를 고치거나 서버를 건드릴 필요가 없습니다.

## 2. 목표와 대상

### 목표
- Notion에 쓴 여행 글이 블로그에 자동으로 보이게 한다.
- 여행지(국가/도시)별로 글을 쉽게 찾아볼 수 있게 한다.
- 모바일과 PC 어디서든 편하게 읽을 수 있게 한다.

### 대상 사용자
- 블로그 운영자(나): Notion에서 글을 작성하고 발행합니다.
- 방문자: 여행 글을 읽고, 여행지별로 찾아보고, 검색합니다.

## 3. 주요 기능

1. **글 목록 가져오기**: Notion 데이터베이스(표 형태로 정리된 글 모음)에서 여행 글 목록을 불러옵니다.
2. **글 상세 페이지**: 글 하나를 선택하면 본문 전체를 보여줍니다.
3. **여행지별 필터링**: 국가/도시를 골라 해당 글만 모아 봅니다.
4. **검색**: 제목이나 키워드로 글을 찾습니다.
5. **반응형 디자인**: 화면 크기(휴대폰, 태블릿, PC)에 맞춰 레이아웃이 자동으로 바뀝니다.

## 4. 기술 스택

| 구분 | 사용 기술 | 쉬운 설명 |
| --- | --- | --- |
| 프론트엔드 | Next.js 15, TypeScript | 화면을 만드는 도구. TypeScript는 실수를 미리 잡아주는 JavaScript입니다. |
| CMS | Notion API (`@notionhq/client`) | 코드가 Notion의 글을 읽어올 수 있게 해주는 통로(API)입니다. |
| 스타일링 | Tailwind CSS, shadcn/ui | 디자인을 빠르게 입히는 도구와 미리 만들어진 예쁜 부품 모음입니다. |
| 아이콘 | Lucide React | 깔끔한 아이콘 모음입니다. |
| 배포 | Vercel | 만든 사이트를 인터넷에 공개해주는 서비스입니다. |

## 5. Notion 데이터베이스 구조

| 속성 이름 | 의미 | Notion 타입 | 설명 |
| --- | --- | --- | --- |
| Title | 제목 | title | 글 제목 |
| Country | 국가 | select | 목록 중 하나 선택 (예: 일본) |
| City | 도시 | select | 목록 중 하나 선택 (예: 도쿄) |
| Tags | 태그 | multi_select | 여러 개 선택 가능 (예: 맛집, 온천) |
| TravelDate | 여행 날짜 | date | 여행 간 날짜 |
| Cover | 대표 사진 | files | 목록에 보일 대표 이미지 |
| Status | 상태 | select | `초안` / `발행됨` |
| Content | 본문 | page content | 페이지 안에 직접 쓰는 글 내용 |

- `Status`가 **발행됨**인 글만 블로그에 보입니다. `초안`은 공개되지 않습니다.

## 6. 화면 구성

| 화면 | 설명 |
| --- | --- |
| 홈 | 최신 여행 글 목록 (대표 사진, 제목, 여행지, 날짜) |
| 글 상세 | 개별 여행기 내용 표시 |
| 여행지별 | 국가/도시별 글 목록 |

## 7. MVP 범위

MVP(최소 기능 제품)는 "꼭 필요한 기능만 먼저 만든 첫 버전"입니다.

**포함**
- Notion API 연동
- 글 목록 및 상세 페이지
- 기본 스타일링
- 반응형 디자인

**나중에 추가 (MVP 이후)**
- 여행지별 필터링 고도화
- 검색 기능

## 8. 구현 단계

1. **Notion API 패키지 설치 및 환경 설정**: `@notionhq/client` 설치, Vite에서 Next.js 15로 전환, 환경 변수 준비
2. **Notion 데이터베이스 생성 및 API 키 설정**: 위 구조대로 데이터베이스를 만들고 API 키(접속 비밀번호)를 발급해 연결
3. **글 목록 페이지 구현**: 홈 화면에서 발행된 글 목록 표시
4. **글 상세 페이지 구현**: 글 선택 시 본문 표시
5. **스타일링 및 최적화**: Tailwind CSS/shadcn/ui로 디자인 다듬기, 반응형 점검, 속도 개선, Vercel 배포

## 9. 주의사항

- API 키는 비밀번호와 같으므로 `.env.local` 파일에만 저장하고 GitHub에 올리지 않습니다.
- Notion에서 글을 수정한 뒤 블로그에 반영되기까지 약간의 시간이 걸릴 수 있습니다.
